CSS custom properties w praktyce

Jak zmienne CSS pomogły mi uporządkować kolory na stronie i dodać tryb ciemny w kilkunastu linijkach kodu.

Na początku nauki wpisywałam kolory bezpośrednio w każdej regule: #4f46e5 tutaj, #4f46e5 tam… Zmiana koloru akcentu oznaczała szukanie i podmienianie w całym pliku. Rozwiązaniem okazały się CSS custom properties, czyli zmienne CSS.

Definicja i użycie

Zmienne definiuje się zwykle w selektorze :root, żeby były dostępne w całym dokumencie:

:root {
  --color-text: #1f2328;
  --color-accent: #4f46e5;
  --radius: 12px;
}

.btn {
  background: var(--color-accent);
  border-radius: var(--radius);
}

Teraz zmiana koloru akcentu to edycja jednej linijki.

Tryb ciemny prawie za darmo

Największa zaleta zmiennych: można je nadpisać w zapytaniu media. Jeśli system użytkownika ma włączony ciemny motyw, podmieniam tylko wartości — reszta stylów zostaje bez zmian: 

@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #0f1115;
    --color-text: #e6e8eb;
    --color-accent: #818cf8;
  }
}

Wartość zapasowa

Funkcja var() przyjmuje drugi argument, który zostanie użyty, gdy zmienna nie jest zdefiniowana: color: var(--color-link, blue);.

Zmienne a JavaScript

W przeciwieństwie do zmiennych z preprocesorów (np. Sass), custom properties działają w przeglądarce, więc można je zmieniać z poziomu JavaScriptu:

document.documentElement.style.setProperty("--color-accent", "#a855f7");

Moje zasady nazywania

  • Nazwy opisują rolę, nie wygląd: --color-accent zamiast --purple.
  • Wspólny prefiks dla grupy: --color-*, --font-*.
  • Wszystkie zmienne w jednym miejscu na początku pliku.

Ta strona korzysta dokładnie z tego podejścia — zajrzyj do pliku styles.css w moim repozytorium.
